# Statically Strict Debugger

A simple smart home lighting interface built with JavaScript, HTML, and CSS. This project serves as a foundational example for transitioning JavaScript applications to TypeScript, emphasizing static typing and strict type checking.

## Live Demo

Explore the live application here: [Statically Strict Debugger Demo](https://rougemeister.github.io/statically-strict-debugger/)

## Project Overview

This project simulates a smart home lighting system, allowing users to interact with different rooms and control their lighting states. It's designed to demonstrate how static typing can enhance code reliability and maintainability in JavaScript projects.

## Features

- Interactive UI representing various rooms in a home.
- Toggle lights on and off for each room.
- Visual indicators for Wi-Fi connectivity status.
- Responsive design suitable for various screen sizes.

## Technologies Used

- **HTML5**: Structure of the web pages.
- **CSS3**: Styling and layout.
- **JavaScript (ES6)**: Functionality and interactivity.

## Getting Started

### Prerequisites

- Modern web browser (e.g., Chrome, Firefox, Edge).
- [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed for development purposes.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rougemeister/statically-strict-debugger.git
   ```

2. Navigate to the project directory:
   ```bash
   cd statically-strict-debugger
   ```

3. Open `index.html` in your preferred web browser to view the application.
